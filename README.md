# Employee Management Excel DataSet

## Project Overview

This project focuses on analysing employee information and developing an interactive Employee Management Dashboard using **Microsoft Excel**.

The objective is to transform raw employee data into meaningful business insights by applying Excel formulas, data-cleaning techniques, Pivot Tables, Pivot Charts, and interactive Slicers.

The analysis covers employee distribution, salary expenditure, average salary, hiring trends, and compensation categories.


## Project Objectives

- Organise and clean employee records.
- Analyse workforce distribution across different job roles.
- Calculate total and average salary expenditure.
- Identify the highest-paid and lowest-paid employees.
- Analyse employee hiring trends over the years.
- Categorise employees based on salary levels.
- Build an interactive dashboard for business reporting.

## Dataset Information

The project uses a sample employee dataset containing **50 employee records**.

The dataset includes the following fields:

| Column | Description |
|---|---|
| EMPLOYEE_ID | Unique employee identification number |
| FIRST_NAME | Employee's first name |
| LAST_NAME | Employee's last name |
| EMAIL | Employee email username |
| PHONE_NUMBER | Employee contact number |
| HIRE_DATE | Employee joining date |
| JOB_ID | Employee job role identifier |
| SALARY | Employee salary value |

Additional calculated columns were created to support workforce and compensation analysis.


## Excel Skills & Functions Applied

### 1. Data Cleaning and Preparation
- Checked for duplicate employee IDs.
- Identified missing or blank values.
- Checked date and salary data formats.
- Organised the dataset using Excel Tables.
- Created additional calculated columns.


### 2. Excel Formulas and Functions

The following Excel functions were used:

- `SUM`, `AVERAGE`, `MAX`, `MIN`
- `COUNTIF`, `SUMIF`, `AVERAGEIF`
- `COUNTIFS`, `SUMIFS`, `AVERAGEIFS`
- `IF`, `AND`, Nested IF
- `VLOOKUP`
- `INDEX` and `MATCH`
- `RANK.EQ`
- `LARGE`
- `YEAR`, `DATEDIF`
- `TEXT`, `IFERROR`


### 3. Advanced Data Analysis

Performed additional calculations to understand employee compensation:

- Salary variance from the overall average.
- Salary variance percentage.
- Individual employee contribution to total payroll.
- Salary ranking.
- Compensation categorisation.
- Identification of employees earning above-average salaries.


### 4. Pivot Tables and Pivot Charts

Created Pivot Tables to analyse:

- Employee count by job role.
- Total salary expenditure by job role.
- Average salary by job role.
- Annual employee hiring trends.
- Employee distribution by salary band.

Created Pivot Charts to visually represent the analysis.


### 5. Interactive Dashboard

Developed an Employee Management Dashboard featuring:

- Total Employees
- Total Payroll
- Average Salary
- Highest Salary
- Lowest Salary
- Average Employee Tenure

The dashboard also includes interactive charts and Slicers to filter the analysis by:

- Job Role (JOB_ID)
- Hiring Year (HIRE_YEAR)
- Salary Band


## Workbook Structure

The Excel workbook is organised into the following worksheets:

| Worksheet | Purpose |
|---|---|
| Raw_Data | Original employee dataset |
| Employee_Analysis | Cleaned data and calculated columns |
| Formula_Lab | Formula practice, calculations and employee lookup |
| Pivot_Analysis | Pivot Tables and Pivot Charts |
| Dashboard | Interactive workforce analysis dashboard |
